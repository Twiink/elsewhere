# 发布素材

图片、音频、视频、字体和光标的发布副本统一保存在此目录，并由 `manifest.json` 管理。

- `images/content/`：项目图片、生活照片、插画和封面。
- `images/textures/`：场景贴图、纸张与界面素材。
- `images/ui/`、`images/cursors/`：地图、图标和光标。
- `audio/`、`video/`、`fonts/`：声音、视频和字体。

`images` 的键是 CDN 的 `space/` 后对象路径，值是以 `/media/` 开头的本地地址。查询参数不影响回退对应关系；本地副本可保留 JPEG、WebP、SVG 等原始格式。新增图片时同时登记 CDN 对象路径与本地文件。

构建按清单将运行需要的素材输出到 `dist/media/`，缺少文件会导致构建失败。CDN 加载成功时不请求本地备用图片；失败或 8 秒未完成时使用本地资源。两种来源都失败时结束加载，不循环重试。

素材制作档案与历史版本保留在仓库忽略的 `assets/` 中。运行网站及构建产物所需的发布副本必须留在这里，不依赖制作档案目录。
